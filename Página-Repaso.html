      ¿Que es el HTML?

      HTML significa HyperText Markup Language(lenguaje de marcado de hipertexto). Es el lenguaje que se utiliza para crear la estructura de las páginas web.

      Por ejemplo HTML permite indicar qué partes de una página son títulos, párrafos, imágenes, enlaces o listas.

      ¿Sabías que ..?

      HTML Es el lenguaje que permite crear la estructuras de las páginas web que visitamos todos los dias

      Algunos ejemplos:

      Amazon

      Wikipedia

      3 curiosidades

      1. HTML no es un lenguiaje de programación, es un lenguaje de marcado
      2. Permite añadir imagenes, videos, enlaces y música
      3. Todas las etiquetas suelen ir entre los simbolos < y >

      ¿Que es el Head?

      En HTML <head> es una parte del documento, donde se coloca la información sobre la página web.

      Esa información normalmente no se muestra directamente dentro de la página, pero ayuda al navegador a interpretarla

      1. Permite adaptar la web a diferentes dispositivos
      2. Ayuda a los buscadore a entender tu página
      3. Permite conectar tu página con CSS

      ¿Que es el Body?

      En HTML el <body> es la parte de una página que contiene todo el contenido que se muestra al usuario en el navegador.

      3 curiosidades

      1. Es como el cuerpo de una persona
      2. Se puede personalizar con CSS
      3. Solo suele haber un body por página HTML
