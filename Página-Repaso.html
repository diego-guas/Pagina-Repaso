Estructura básica de una página HTML

Los elementos fundamentales de una página HTML son:

  • HTML
    • Etiqueta: <html>
    • Elemento principal y raíz del documento HTML.
    • Todo el contenido del documento está incluido en él.
  • HEAD
    • Etiqueta: <head>
    • Etiqueta: < title>Titulo
    • Etiqueta: <meta>Para proporcionar inf oculta
      • <meta charset=utf-8>Indica que tabla de caracter vamos a utilizar
      • <meta name= "autor" content= >Indica el nombre de la persona o entidad que creó el contenido
      • <meta copyright=content= >Para declarar de forma clara los derechos del autor y la popiedad del contenido
      • <meta name= "keywords">Para indicar palabras claves o temas principales
      • <meta name ="description" content => Contiene la idea proncipal
    • BODY
      • Etiqueta: <h1> Para poner un titulo
      • Etiqueta: < h3>Para poner un titulo mas pequeño
      • Etiqueta: <p> Inicia un párrafo
      • Etiqueta: < br>Salta un parrafo
      • Etiqueta: <pre>Para dar tantos espacios como deseo
